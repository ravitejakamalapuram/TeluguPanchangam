These are Claude Design canvas files. They need the canvas runtime (`support.js`, not included) to render, so open them from the canvas link above. The share-card boards show PNG renders of the real exporter (`ui/share-card.js`), uploaded to the canvas, so the image links work only there. Explored-and-rejected layouts are left out on purpose. There is no sankalpam board yet (issue #41).

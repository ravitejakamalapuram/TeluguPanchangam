## 5. User adoption plan

### 5.1 Reduce install friction (weeks 1–2)
- Optional `geolocation` (section 3): the install dialog then only shows the new-tab warning.
- **First-run onboarding** (3 screens, in Telugu by default): language → city (US metro list first if the browser timezone is American) → optional DOB for rasi. Today a new user lands on a Hyderabad page with no prompt.
- Explain Chrome's "Change back to Google?" bubble on first open; it is the largest single source of new-tab-extension uninstalls. A one-line note under the clock on day 1 ("Keep this new tab to see today's panchangam") is enough.

### 5.2 Retention (weeks 2–6)
- Weekly-return hooks already exist (festivals, reminders); make them visible: an "Upcoming this week" strip (Ekadashi, Pradosham, Sankashti, festivals) on the main view.
- Ekadashi / Sankashti / Amavasya **lunar reminders** pre-seeded and toggleable (they are the most-searched recurring observances).
- Daily horoscope that actually changes daily (2.P2) — the main reason people come back to a rasi card.

### 5.3 Growth loops (weeks 4–12)
- Share card (4.6) and rating prompt (4.7).
- Ask once (opt-in) for an email address only if a "festival calendar newsletter" is ever wanted — otherwise keep the zero-network promise, which is a selling point; do not add analytics.
- Measure with the data CWS already gives (weekly users, installs/uninstalls by region in the Developer Dashboard) instead of in-app tracking.

## 7. Re-review against Telugu panchangam conventions

Second pass, checking the output against what a printed Telugu (చాంద్రమాన, అమాంత) panchangam
shows and how Telugu households and temples (TTD, Bhadrachalam, Srisailam) fix festival days.
Festival dates below were produced by running the engine for Hyderabad over 2025–2026.

The basics are right: amanta lunar months with adhika detection, lunar ritus (Chaitra–Vaishakha
= Vasanta), Udaya tithi/nakshatra, Telugu tithi names (పాడ్యమి, విదియ, తదియ, చవితి …), Prabhava
cycle with 2026–27 = పరాభవ, Rahu Kalam and Yamagandam weekday parts, Abhijit, Varjyam (త్యాజ్యం)
table, Telugu Hanuman Jayanti on Vaishakha Bahula Dashami, Bhogi/Sankranti/Kanuma/Mukkanuma off
the real Makara transit, Vinayaka Chavithi in madhyahna, Vijayadashami in aparahna, Deepavali in
pradosha. Items below are what does **not** match Telugu practice.

### 7.2 Missing Telugu festivals and vratams

Most-observed first. Each is a tithi/weekday/solar rule the engine can already express.

- **P1, Telangana:** బతుకమ్మ (ఎంగిలి పూల బతుకమ్మ on Bhadrapada Amavasya → సద్దుల బతుకమ్మ on Ashwayuja Shukla Ashtami), బోనాలు (Ashadha Sundays), నాగుల పంచమి (Shravana Shukla Panchami).
- **P1, Andhra:** అట్లతద్ది (Ashwayuja Bahula Tadiya, moonrise), ఉండ్రాళ్ల తద్దె (Bhadrapada Bahula Tadiya).
- **P1, everyone:** కార్తీక సోమవారాలు (Mondays in Karthika); కార్తీక మాసం ప్రారంభం; శ్రావణ మంగళవారాలు (మంగళగౌరీ వ్రతం) and శ్రావణ శుక్రవారాలు; ధనుర్మాసం ప్రారంభం (Sun enters Dhanus); ఉత్థాన ఏకాదశి.
- **P1, monthly recurring:** every ఏకాదశి with its name (నిర్జల, తొలి, పరివర్తిని …), సంకటహర చతుర్థి (moonrise rule), ప్రదోషం (trayodashi at pradosha), మాస శివరాత్రి, పౌర్ణమి/అమావాస్య.
